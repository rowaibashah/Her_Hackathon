# PENOVA AI — WRITE. RECORD. LEARN.

A student study-hub web app (MVP prototype) built with plain HTML, CSS and JavaScript.

## Features
- **Digital Notes** — write, auto-save locally, search and export to PDF
- **Lecture Assistant** — paste or dictate (mic) lecture transcripts
- **AI Summary / AI Exam Maker / Smart Revision** — powered by the Google Gemini API
- **Smart Pen Prototype** — simulated BLE pen connection and a double-underline highlight demo

## Run locally
1. Download or clone this repository.
2. Open `index.html` in Chrome or Edge.

## Gemini API key
Get a free key from [Google AI Studio](https://aistudio.google.com/apikey), then click **Set API Key** in the app.
The key is stored only in your browser's local storage — never commit a key to GitHub.
